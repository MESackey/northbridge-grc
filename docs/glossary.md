# Glossary (write each definition in your OWN words)

| Term | My definition |
|---|---|
| Asset | Something Northbridge owns that has value and needs protecting, like the patient database |
| Threat | Something that could cause harm, like a criminal who wants patient data or like a bot continuously scanning for credentials |
| Vulnerability | A weakness the threat could use, like a storage bucket set to public |
| Risk | The chance of harm and how bad it would be, for example, where patient data is exposed through a public bucket |
| Inherent risk | The score before any controls |
| Residual risk | The score after controls, this is whatever is left |
| Control | Something that reduces risk, like blocking public access on all buckets |
| ISMS | The company's official playbook of policies and controls that protects sensitive data from breaches while proving to auditors that Northbridge is following the rules |
| Statement of Applicability (SoA) | A mandatory document that acts as Northbridge's master checklist, explicitly stating which security controls the company have chosen to implement, why they are necessary, and how they protect Northbridge data |
| Three Lines of Defence | A management framework that clarifies who does what when managing risk and compliance, ensuring nothing slips through the cracks, that would be the teams running controls, risk and complaince oversight, and internal audit |
| CMDB | Configuration Management Database is Northbridge's central inventory of every single IT asset, software, and data flow in the company, explicitly showing how they are connected |
| TPRM | Third Party Risk Management is the process of identifying, assessing, and controlling the security risks that come from Northbridge's vendors, suppliers, and external partners |
| SIEM | Security Information and Event Management is Northbridge's centralised security radar that detects, collects logs and alert on suspicious activity |
| IaC | Infrastructure as Code, instead of an engineer manually clicking buttons in a cloud console to set up a server, they write a script using tools like Terraform or CloudFormation to spin it up automatically |
| SAST / SCA | Static Application Security Testing and Software Composition Analysis are two automated code-scanning methods that work together to secure the company's software applications during development, embedding risk management directly into Northbridge's pipeline |
| CI/CD pipeline | Automatically tests changes and releases them, and that is where our security checks run before merging |
| Shift-left | The practice of moving security, risk management, and compliance checks to the earliest possible stage of the software development lifecycle |
| Evidence | The verifiable, unalterable proof that Northbridge is actuallydoing what its policies say it is doing |
